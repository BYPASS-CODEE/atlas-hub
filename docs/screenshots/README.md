# Screenshot capture guide

برای انتشار repository، از صفحه‌ی اصلی اجرای واقعی Atlas Hub در این viewportها screenshot تهیه کنید:

- `home-mobile.png` — `390 × 844`
- `home-tablet.png` — `820 × 1180`
- `home-desktop.png` — `1440 × 900`

دستور اجرا:

```bash
npm install
npm run dev
```

سپس `http://localhost:3000/` را در مرورگر باز کنید و تصاویر را با همین نام‌ها در همین پوشه ذخیره کنید. قبل از capture مطمئن شوید اطلاعات شخصی، token، password یا داده‌ی تستی در صفحه نمایش داده نمی‌شود.
